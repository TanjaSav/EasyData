🔌 Local Server Check

Database Service: Ensure your local node engine is active by running npm run dev inside the project root before using the extension.

Cloud Fallback: If the local server is offline, the extension automatically routes requests securely through the public cloud endpoint https://easydata.is/mcp.

⚠️ Troubleshooting Tips

Reload Extension: If the loading circle fails to close, go to chrome://extensions, toggle the EasyData Connector **Off** and **On**, and refresh your chat page.

OpenAI Keys: Bypass Codex rate limits by configuring your OPENAI_API_KEY inside the project's .env file.
