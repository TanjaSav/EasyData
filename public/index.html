Sample Prompt to Activate:
Chat Prompt
Use EasyData MCP. Create a simple table called workouts with columns: exercise_name TEXT, duration_minutes INTEGER

How to write the prompt

Write the prompt like a short product brief. Start with the app goal and who will use it, then list the data you need to store as tables and fields, including field types when you know them. Describe the main actions users should be able to do, such as submit, edit, review, score, upload files, filter, or delete records. Mention any images or documents that should be uploaded, what should be shown on each page, and any rules such as required fields, score ranges, teacher-only comments, or sorting by newest first.
