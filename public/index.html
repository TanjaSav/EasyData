The API stays small enough to explain.

AI tools use the same endpoints that a browser app uses, so the generated code remains inspectable.

  1. 1

    Create an app. EasyData returns an app id and token.

  2. 2

    Define tables. Add columns for the teacher's workflow.

  3. 3

    Use fetch. Insert, update, query, and delete rows from the generated page.

await fetch('/apps/{appId}/tables/submissions/rows', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer app_token'
  },
  body: JSON.stringify({
    student_name: 'Alex',
    photo_url: '/uploads/project.jpg'
  })
});
