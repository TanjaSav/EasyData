Privacy by Design

GDPR & Data Protection Guide

Learn how EasyData keeps classroom data secure, handles sensitive fields, and helps you design privacy-compliant student projects.

⚠️ Sensitive Data Warnings

If you attempt to create a database schema that contains columns referencing personal identifier information (such as student_name, photo, health, address, behavior, disability, or national_id), EasyData's Model Context Protocol (MCP) server automatically flags these columns and triggers a security warning.

To bypass this warning and successfully build the table, you or the AI assistant must explicitly declare confirmSensitiveData: true. This safeguards against accidental personal data harvesting.

📅 Data Retention Policies

Under GDPR, student data should only be kept for as long as it is necessary for school projects. By default, every new EasyData application is initialized with a recommended retention configuration: review and delete at the end of the school year.

Retention APIs
GET/apps/:id/retention
PUT/apps/:id/retention

Teachers can update the retention configuration to set custom review dates, or disable retention alerts entirely if no personal student data is processed.

💾 Data Export and deletion

Educators can fully export student records to a JSON format before purging databases, fulfilling the GDPR right to data portability. Deleting database records also deletes associated uploaded files.

Deletion & Export APIs
GET/apps/:id/export
DELETE/apps/:id
DELETE/apps/:id/tables/:table/rows/:rowId

⚖️ The Three Questions Checklist

Before sharing any EasyData web application link with your students, ensure you have answered these three primary privacy questions:

  • What data is collected? Collect only what is required (e.g. use student initials or IDs instead of full names).
  • Who has access? Secure database table tokens so only graders and administrators can view submissions.
  • When is it deleted? Set a clear review date to clean files and database rows once grading finishes.

🔒 Security Safeguards

EasyData incorporates developer safeguards to protect data integrity, including signed short-lived URLs for student photos, automatic request rate-limiting, strict file signature verification, and secure audit logging to track schema modifications.
