Hosted vs Local MCP

Cloud URLs (Connectors GUI): Ideal for hosted environments. Claude's cloud models connect directly via HTTP/SSE. The URL must be public and secure: https://easydata.is/mcp

Local stdio (Config File): Ideal for local-only scripts. Requires setting up command hooks in the local configuration JSON files

Integration Tips

Explicit Activation: When starting a new conversation with Claude, state clearly: "Use the EasyData MCP connector" to ensure Claude binds the connection.

Permission Prompts: Claude will ask for explicit confirmation before reading or writing data. Choose Always Allow to bypass repeated clicks
